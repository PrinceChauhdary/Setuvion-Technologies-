COMMON QUESTIONS

A few things to know before you start.

Clear answers about preview access, data handling, and target support.

Does AutoVerify Studio upload test data?

The current preview is designed for local use and does not upload customer logs or test results to a cloud service by default.

Will it work with every Android automotive target?

No. Available properties and hardware features depend on the services and permissions exposed by each target. Simulator output is generated data and does not prove physical vehicle behavior.

Can I download the application now?

A distributable package and release terms are not ready yet. Use the contact form to ask about the developer preview.

What happens to a contact-form inquiry?

The inquiry is stored on the website’s configured server volume so the Setuvion team can respond. Do not include credentials, customer logs, or confidential vehicle data.
